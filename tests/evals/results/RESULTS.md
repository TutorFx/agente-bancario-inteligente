# Resultados da avaliação dos agentes

> Gerado por `pytest -m eval` (tests/evals/report.py); não edite à mão.

Nenhuma execução completa da suíte foi publicada ainda. Para gerar este resumo (requer
`GEMINI_API_KEY` no `.env`; custa chamadas à API):

```bash
EVAL_RUNS=1 pytest -m eval
```

Uma execução que cobre todos os cenários do dataset reescreve este arquivo; execuções
parciais (`-k ...`) só atualizam o relatório local `tests/evals/reports/latest.md`.
